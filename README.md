# 📐 STATIX PRO (سامانه تحلیل استاتیک عمران - دسکتاپ و اندروید)

نرم‌افزار مهندسی، سریع و دقیق برای حل تمامی مسائل کتاب **مکانیک برداری برای مهندسان: استاتیک (Ferdinand P. Beer, E. Russell Johnston Jr.)** به صورت **همزمان روی دسکتاپ و گوشی‌های اندروید**.

---

## 📱 ۱. نحوه استفاده روی اندروید (Android Mobile & Tablet)

نرم‌افزار مجهز به استانداردهای **PWA (Progressive Web App)** و رابط کاربری ریسپانسیو لمسی است:

### روش اتصال آسان با QR Code:
1. کامپیوتر و گوشی اندروید را به یک مودم یا هات‌اسپات (Wi-Fi) یکسان وصل کنید.
2. در نرم‌افزار روی دکمهٔ **«📱 اتصال به اندروید»** در بالای صفحه کلیک کنید.
3. با دوربین گوشی اندروید یا نرم‌افزار بارکدخوان، **کد QR** نمایش‌داده‌شده را اسکن کنید.
4. آدرس نرم‌افزار در مرورگر کروم گوشی باز می‌شود.
5. **نصب اپلیکیشن روی اندروید:**
   - منوی ۳ نقطه مرورگر Chrome را باز کنید.
   - گزینه **«افزودن به صفحه اصلی / Add to Home screen»** یا **«نصب برنامه / Install app»** را لمس کنید.
   - نرم‌افزار با آیکون اختصاصی در لیست برنامه‌های گوشی شما نصب شده و به صورت تمام‌صفحه (بدون نوار آدرس مرورگر) مثل یک اپ بومی اندروید اجرا خواهد شد.

---

## 💻 ۲. نحوه استفاده روی دسکتاپ (Windows Desktop)

برای دسکتاپ دو حالت در اختیار شماست:

### حالت اول: نرم‌افزار مستقل دسکتاپ (Native Desktop Window)
روی فایل **`run_desktop.bat`** دوبار کلیک کنید. 
یک پنجره مستقل دسکتاپ (Native App) بدون نوار مرورگر و با عملکرد مستقل برای شما باز می‌شود.

### حالت دوم: اجرای تحت وب دسکتاپ
روی فایل **`run.bat`** دوبار کلیک کنید یا دستور زیر را در ترمینال بزنید:
```bash
python run.py
```
سپس در مرورگر به آدرس `http://localhost:8000` بروید.

## 🏗️ سرفصل‌های بیر جانسون تحت پوشش:

1. **تیرها و قاب‌ها (Ch 7):** دیاگرام‌های پیوسته برش $V(x)$ و لنگر $M(x)$، تیرهای ژربر، انواع تکیه‌گاه‌ها و بارهای گسترده/متمرکز.
2. **خرپاهای دوبعدی (Ch 6):** تحلیل ماتریسی FEM، تفکیک نیروهای کششی (آبی)، فشاری (قرمز) و اعضای صفر نیرویی.
3. **بردارها و تعادل ذره (Ch 2 & 3):** ضرب‌های برداری، زوایای هادی و تعادل ۳D کابل‌های معلق.
4. **اجسام صلب و لنگر (Ch 3 & 4):** لنگر حول نقطه و محور، سیستم‌های معادل و آچار پیچی (Wrench).
5. **مرکز سطح و پاپوس (Ch 5):** مقاطع مرکب، بازشوهای توخالی و حجم دوران.
6. **ممان اینرسی و دایره مور (Ch 9):** ممان‌های اصلی، محورهای خنثی و رسم دایره مور.
7. **کابل‌ها (Ch 7):** کابل‌های سهموی، کشش بیشینه $T_{max}$ و افتادگی.
8. **اصطکاک (Ch 8):** بررسی لغزش در برابر واژگونی (Slip vs Tip) و اصطکاک تسمه (فرمول کاپستان).
9. **کار مجازی و پایداری (Ch 10):** بررسی مشتقات انرژی پتانسیل و پایداری تعادل.
